Link Referents

Use this page to indicate when two or more references in the source documents refer to the same individual.

In Stolen Relations, a Referent is a reference to a person found in a source document. A Person represents the actual individual to whom one or more Referents may refer.

For example, if two different records mention “Prince” and you determine that both references describe the same individual, those two Referents should be associated with (or Linked to) the same Person.
